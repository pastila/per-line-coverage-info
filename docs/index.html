per-line-coverage-info

Custom plugin repository for receiving updates straight from GitHub, bypassing JetBrains Marketplace.

Add the repository to your IDE

  1. Open Settings → Plugins.
  2. Click the ⚙ (gear) icon → Manage Plugin Repositories…
  3. Click + and paste: 
    https://yakov255.github.io/per-line-coverage-info/updatePlugins.xml
  4. Click OK. The IDE will now check this repo together with Marketplace and offer updates the usual way.

Manual update manifest

The current manifest lives at updatePlugins.xml. It is regenerated automatically on every GitHub release.
